# my_franka: learning to pick up objects in OmniGibson

A Franka arm on a table in the `Rs_int` scene, picking up an apple (and 11 other objects), built up from a scripted
pick to imitation learning, RL, vision policies, zero-shot robot foundation models and VLM-based control.
Everything runs inside BEHAVIOR-1K / OmniGibson (use the `behavior` conda env; add `OMNIGIBSON_HEADLESS=1` for
headless runs).

## Results (same simulator, same unseen evaluation layouts)

| Method | Robot training data | Apple, 50 layouts | 12-object suite, 96 episodes |
|---|---|---|---|
| Scripted expert (privileged state) | none | 92% | - |
| State-based BC (MLP), Markov expert | 200 demos | 92% | - |
| Diffusion policy, wrist camera (LeRobot) | 962 demos | **90%** | apple only |
| pi0.5-DROID, zero-shot | DROID only | 0/8 | **0/96** |
| VLM harness, frozen Qwen2.5-VL-7B | **none** | **88%** (v3) | **84%** (v2) |
| VLA-0-style, Qwen2.5-VL-3B + LoRA | 962 demos | 30% | apple only |

Robustness of the diffusion policy (200 layouts per condition): lighting x0.5 / x2 no clear effect;
brick walls 84% and red apple 82.5% (vs ~91% baseline); wood-grain table 0/50.

## Typical commands

```bash
OMNIGIBSON_HEADLESS=1 python my_franka/step9_collect_vision.py --workers 2 --target 1000   # vision demos
python my_franka/step10_to_lerobot.py --name franka_apple_wrist_all                         # LeRobot dataset
OMNIGIBSON_HEADLESS=1 python my_franka/step11_eval_vision.py --ckpt <ckpt>/pretrained_model  # evaluate a LeRobot policy
OMNIGIBSON_HEADLESS=1 python my_franka/robustness_eval.py                                  # visual robustness
OMNIGIBSON_HEADLESS=1 python my_franka/pi0_zero_shot_eval.py --layouts 8                   # pi0.5 zero-shot suite
OMNIGIBSON_HEADLESS=1 python my_franka/vlm_harness_eval.py eval --layouts 8                # VLM harness suite
python my_franka/vla0_train.py --steps 2600 && OMNIGIBSON_HEADLESS=1 python my_franka/vla0_eval.py
```

## Lessons worth remembering

- The OmniGibson IK controller is a one-step Jacobian solve: command targets 1-3 cm ahead; close apples hit joint limits.
- An imitation teacher must act only on what the student observes (a hidden timer cost 22 points of BC success).
- Plain PPO on a BC policy with ~10 episodes per update mostly learns noise; anchor it to BC.
- pi0.5-DROID needs 16:9 letterboxed images; its wrapper was verified on real DROID data (correlation 0.58 vs 0.05 chance).
- Qwen2.5-VL grounding needs resolution: 448x252 boxes were often off by an object width, 896x504 boxes landed on the object in 71/72 views.
- Sim processes leak memory and slow down; restart long collections periodically; never `pkill -f` a pattern in your own command.
